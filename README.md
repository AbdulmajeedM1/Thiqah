### First setup after cloning

```powershell
git clone https://github.com/AbdulmajeedM1/Thiqah.git
cd Thiqah
flutter pub get
dart run tool/create_demo_admin.dart
flutter run
```

The administrator seed is intentionally excluded from Git. Generate it once after cloning; the tool prints the new local administrator password. Keep that password privately. If the seed already exists, the tool refuses to replace it. Do not regenerate it to reset an existing installed account.

## الدخول والحسابات

- يبدأ التطبيق بشاشة تسجيل الدخول باسم المستخدم أو البريد وكلمة المرور.
- رابط «ليس لديك حساب؟ إنشاء حساب جديد» يفتح نموذج الاسم الكامل، اسم المستخدم، البريد، الجوال السعودي، المدينة، نوع الحساب (عميل أو مقدم خدمة)، كلمة المرور وتأكيدها والموافقة على الشروط.
- يتحقق النموذج من البيانات المطلوبة، ويمنع تكرار اسم المستخدم والبريد والجوال. يقبل الجوال الأرقام العربية والفارسية والإنجليزية.
- حساب المدير مُعد مسبقًا باسم `admin`؛ كلمة المرور الأولية تُسلّم لصاحب المشروع خارج ملفات المصدر. يمكن تغييرها من قائمة خيارات الحساب في لوحة المدير.
- التسجيل العام لا يسمح بإنشاء مدير. المدير يعرض الحسابات، يبحث فيها، يراجع بياناتها ويوقف أو يعيد تفعيل حسابات المستخدمين.
- الحسابات محفوظة محليًا باستخدام `flutter_secure_storage`. كلمات المرور مشتقة باستخدام PBKDF2-HMAC-SHA256 وملح عشوائي؛ لا تُحفظ كنص واضح. الجلسة تستمر حتى تسجيل الخروج أو انتهاء مدتها (7 أيام).
- تغيير كلمة المرور يلغي جلسات الحساب السابقة، وإيقاف الحساب يمنع الدخول به. تسجيل الخروج يغلق الصفحات المحمية ويزيل بيانات الحساب من الذاكرة.

**نطاق النسخة:** الحسابات موجودة على الجهاز الذي أُنشئت فيه فقط. الطلبات المنشورة تظهر لمقدمي الخدمة على نفس الجهاز، وعروضهم تعود للعميل صاحب الطلب. المسودات خاصة بالعميل، والمرفقات والمحادثة متاحة للعميل ومقدم الخدمة المختار. لا توجد مزامنة بين أجهزة مختلفة. البريد والجوال بيانات للنموذج دون إرسال OTP. الدفع والمحفظة محاكاة تعليمية ولا توجد تحويلات مالية.

## وظائف التطبيق

- الرئيسية وست فئات خدمات، طلبات العميل وواجهة مقدم الخدمة.
- إنشاء طلب وتحديد الميزانية والمدينة والتفويض والاستعجال، وحفظ المسودة وتعديلها ونشرها.
- البحث والفلترة وإضافة ملفات محلية وتصدير نسخة منها.
- شاشات العروض والتسليم والتقييم والنزاع، ومحادثات وإشعارات ومحفظة تجريبية محلية.
- عرض بيانات الحساب وتغيير كلمة المرور واللغة وتسجيل الخروج.
- لوحة إدارة الحسابات المحلية، مع حماية حساب المدير من الإيقاف.

يبدأ العميل الجديد بقائمة طلباته الفارغة، بينما يرى مقدم الخدمة الطلبات المنشورة في السوق المحلي. لا توجد عروض أو ردود تلقائية. النزاع المحلي يتوقف عند حالة النزاع دون تسوية مالية.

## تجربة طلب بين حسابين

1. أنشئ حساب عميل، وأنشئ الطلب ثم اضغط «نشر الطلب». المسودة لا تظهر في السوق.
2. سجّل الخروج وادخل بحساب مقدم خدمة على نفس الجهاز.
3. من «الطلبات» افتح طلب العميل واضغط «قدّم عرضك» ثم أرسل السعر والمدة.
4. ادخل بحساب العميل، وافتح الطلب واختر عرض مقدم الخدمة، ثم نفّذ الدفع التجريبي.
5. بعد اختيار العرض يستطيع الطرفان تبادل الرسائل والمرفقات. ادخل بمقدم الخدمة لتسليم المعاملة، ثم بالعميل لتأكيد الإنجاز والتقييم.
6. تظهر الأرباح التجريبية لمقدم الخدمة المختار وحده، ويمكن تجربة سحبها من المحفظة.

## التشغيل والبناء

اختُبر المشروع باستخدام Flutter 3.47.4 وDart 3.13.3.

```powershell
cd <repository-folder>
flutter pub get
flutter run
```

اختر محاكي Android أو هاتفًا مع تفعيل USB debugging. لا تحتاج إلى تشغيل أي خدمة خلفية. تشغيل iOS يتطلب macOS وXcode وإعداد التوقيع. التطبيق يستهدف Android وiOS؛ استخدام `dart:io` في تخزين الملفات لا يدعم الويب.

```powershell
flutter analyze
flutter test
flutter build apk --debug
```

ملف Android الناتج: `build/app/outputs/flutter-apk/app-debug.apk`. هذا إصدار تطوير لتجربة المشروع وتثبيته على الهاتف.

## التخزين

- حسابات الجهاز والجلسة في مخزن النظام المحمي.
- الطلبات والعروض والمحادثات في `Application Support/thiqah_marketplace_v2.json`، مع ربط الطلب بمعرّف العميل والعرض بمعرّف مقدم الخدمة. يحفظ الملف أيضًا التفضيلات والإشعارات والسحب التجريبي لكل حساب على حدة. الكتابة متسلسلة باستخدام ملف مؤقت.
- تُستورد الطلبات الموجودة في ملفات `accounts/<accountId>.json` تلقائيًا مرة واحدة عند أول دخول بعد التحديث، حتى لو دخل مقدم الخدمة أولًا. تبقى الملفات القديمة دون تغيير كنسخة احتياطية، ولا تُعاد إضافتها في كل دخول.
- المرفقات ملفات محلية داخل بيانات التطبيق.
- تسجيل الخروج لا يحذف الحساب أو طلباته؛ تعود البيانات عند الدخول مجددًا.
- بيانات النسخة التجريبية السابقة قبل إضافة الحسابات تبقى في ملفها القديم، ولا تُنسب تلقائيًا إلى أي حساب جديد.
- `assets/demo_admin.json` يحتوي بيانات المدير الأولية ومشتق كلمة المرور فقط. يُقرأ عند إنشاء مخزن الحسابات لأول مرة؛ تحديث التطبيق لا يستبدل كلمة مرور غيّرها المستخدم.
- `tool/create_demo_admin.dart` أداة إعداد أولي ترفض استبدال ملف المدير الموجود؛ ليست خطوة مطلوبة لتشغيل المشروع الحالي.

## الكتابة بالعربية

- في المحاكي أضف «العربية (المملكة العربية السعودية)» من Gboard ← Languages، وبدّل اللغة بالضغط المطول على المسافة.
- فعّل لوحة الشاشة عند توصيل كيبورد الكمبيوتر. إذا ظهر شريط القلم بدل الأحرف، عطّل Gboard ← Write in text fields ← Use stylus to write in text fields.
- حقول الميزانية والعرض والمدة تقبل الأرقام العربية والفارسية والإنجليزية. أمثلة: `١٬٢٣٤٫٥٠` للمبلغ و`٧` للمدة.
- جرى التحقق من الكتابة العربية بأزرار Gboard على المحاكي، بالإضافة إلى اختبارات النص والأرقام العربية.

## الملفات الأساسية

- `lib/main.dart`: التشغيل والهوية واللغة والتوجيه حسب حالة الدخول.
- `lib/src/auth.dart`: بيانات الحساب وإدارة الجلسة ورسائل الأخطاء.
- `lib/src/local_auth.dart`: التسجيل والدخول والصلاحيات والحفظ المحلي للحسابات.
- `lib/src/auth_screens.dart`: الدخول والتسجيل وتغيير كلمة المرور.
- `lib/src/admin_screen.dart`: لوحة المدير وإدارة الحسابات.
- `lib/src/store.dart`: السوق المحلي المشترك وملكية الطلبات والعروض وقواعد انتقال الحالات وترحيل الملفات القديمة.
- `lib/src/app.dart`: الرئيسية والتنقل والحساب.
- `lib/src/request_screens.dart`: الطلبات والعروض والتسليم والنزاع والتقييم.
- `lib/src/secondary_screens.dart`: المحادثات والإشعارات والمحفظة والمستندات.
- `lib/src/number_input.dart`: دعم إدخال الأرقام العربية والفارسية.
- `test/`: اختبارات الحسابات والصلاحيات والتخزين والعزل والتنقل وقواعد الطلبات واللغة.
